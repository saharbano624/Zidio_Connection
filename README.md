# Zidio Connection

**Zidio Connection** is a web-based platform developed during my internship at **Zidio Development** to connect students with companies for internships and job opportunities. The project focuses on providing a seamless experience through an efficient backend and database management system.

---

## Features

* **User Authentication** – Secure login and registration system
* **Profile Management** – Manage student and company profiles
* **Job Posting & Application** – Companies can post jobs, students can apply
* **RESTful APIs** – Smooth communication between frontend and backend
* **Database Optimization** – Efficient queries for improved performance
* **Scalable Backend Architecture** – Built to handle growing user base

---

## Tech Stack

* **Backend:** Java, Spring Boot
* **Database:** MySQL
* **Tools & Environment:** IntelliJ IDEA / Eclipse, Maven, Git, GitHub

---

## Project Highlights

* Developed secure RESTful APIs for seamless frontend-backend integration
* Implemented CRUD operations for job postings and applications
* Optimized database queries for faster performance
* Gained hands-on experience in backend development and API integration
* Learned the importance of writing clean, maintainable, and scalable code

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/zidio-connection.git
   ```
2. Import the project in **IntelliJ IDEA** or **Eclipse**
3. Set up the **MySQL** database using the provided scripts
4. Configure database credentials in `application.properties`
5. Run the Spring Boot application:

   ```bash
   mvn spring-boot:run
   ```

---

## Usage

* Access endpoints via REST API clients like Postman
* Register users, post jobs, and apply for jobs using the API routes
